# CodeNibbler - Quick Start Guide

## Getting Started

### Step 1: Open the Application
1. Open `index.html` in your web browser for the landing page
2. Click "Get Started" or navigate to Dashboard using the navigation menu

### Step 2: Dashboard (main.html)

#### First Things First - Set Up Categories
**Habits:**
1. Go to "Habits & Categories" section
2. Add your first habit category (e.g., "Health", "Productivity", "Learning")
3. Click "Add Category"

**Journal:**
1. Go to "Journal & Life Document" section
2. Create categories like "Personal", "Work", "Reflection"

#### Add Your First Habit
1. Select category from dropdown
2. Enter habit name (e.g., "Morning Run")
3. Set time (e.g., 06:00)
4. Click "Add Habit"
5. Check off when completed!

#### Daily Affirmations Setup
1. Click on time periods (Morning, Afternoon, Evening, Dinner, Night)
2. Write your affirmation
3. Click "Add Affirmation"
4. Your affirmations will rotate on the display

#### Track Your Day
1. **Habits**: Check them off as you complete
2. **To-Do List**: Add time-based tasks
3. **Courses**: Add courses and update progress
4. **Journal**: Write your daily reflections

### Step 3: Skills Dashboard
1. Add your skills with proficiency level
2. Track your progress across multiple skills
3. Update as you improve

### Step 4: Blog (blog.html)

#### Create Categories
1. Click "Add Category" under category management
2. Create categories like "Tutorial", "News", "Personal"

#### Write Your First Blog Post
1. Enter title (e.g., "My Web Dev Journey")
2. Select category
3. Add tags (e.g., JavaScript, Web Dev)
4. Write your content
5. Add featured image URL (optional)
6. Click "Publish Post"

#### Manage Your Blog
1. View all posts in the grid
2. Use search to find posts
3. Filter by category or status
4. Click "View" to see full post
5. Click "Edit" to modify
6. Click "Delete" to remove

## Data & Storage

### Where is my data stored?
- All data is stored in your browser's LocalStorage
- No account needed!
- Data persists between sessions
- Private and secure

### How to backup?
1. Open Browser DevTools (F12)
2. Go to Application → LocalStorage
3. Look for `codenibbler-data` and `codenibbler-blog`
4. Copy the JSON values to a text file

### How to restore?
1. Open DevTools
2. Go to Application → LocalStorage
3. Paste the backed-up JSON values
4. Refresh the page

## Troubleshooting

### "My data disappeared!"
- Check if you're in a private/incognito browser window
- LocalStorage doesn't work in private mode
- Try a regular browser window

### "Data not saving"
- Check browser storage quota
- Clear cache if corrupted
- Export backup and refresh

### "Images not showing"
- Ensure image URL is correct
- Use HTTPS URLs for security
- Check internet connection

### "Can't find a post"
- Use search filter
- Check category filter
- Filter by status (Published/Draft)
