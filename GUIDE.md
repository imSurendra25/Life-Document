## Quick Start in 30 Seconds

### 1. Open Dashboard
```
Open main.html in your browser
```

### 2. Create First Habit
```
Go to "Habits & Categories"
→ Add category → Add habit with time
→ Check off when done!
```

### 3. Write Affirmation
```
Select time period (Morning, Afternoon, etc.)
→ Type affirmation → Add
→ See it displayed above!
```

### 4. Track Daily Tasks
```
Enter task and time → Add Task
→ Check off as you complete
→ See daily progress update!
```

### 5. Manage Learning
```
Add course name and progress %
→ Update as you progress
→ Delete when complete!
```

### 6. Create Blog Post
```
Open blog.html
→ Write title, content, category
→ Publish or save as draft!
```

## Common Questions

### Q: Where is my data stored?
**A:** In your browser's LocalStorage (same place bookmarks are stored)

### Q: Is my data private?
**A:** 100% Yes! Everything stays on your device

### Q: Can I use on multiple devices?
**A:** Each browser has separate storage. You can export/import data

### Q: What if I clear browser cache?
**A:** Data might be deleted. Export backup first!

### Q: Can I share my blog?
**A:** Export posts and share as text. Future: Direct sharing feature

### Q: How much data can I store?
**A:** About 5-10MB per browser (years of data)

### Q: Works offline?
**A:** Yes! Everything works without internet

### Q: Mobile app available?
**A:** Responsive web app. Works on phone browsers
