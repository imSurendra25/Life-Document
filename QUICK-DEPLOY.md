# 🚀 QUICK START: Deploy in 5 Minutes

## ⚡ Fastest Method: Netlify (Drag & Drop)

### Step 1: Prepare Files
```
Create folder "codenibbler" with all your files:
- indexx.html → rename to index.html
- main.html
- blog.html
- style.css
- main.css
- blog.css
- main.js
- blog.js
- landing-script.js
- men.jpg
- favicon.ico
```

### Step 2: Go to Netlify
```
https://netlify.com → Sign up (free)
```

### Step 3: Drag & Drop
```
Click "Add new site" → "Deploy manually"
Drag your folder into the box
```

### Step 4: Wait 30 Seconds ⏳
```
Your site appears:
https://codenibbler.netlify.app
```

**DONE! 🎉**

## 🐙 Alternative: GitHub Pages (5 minutes)

### Step 1: Rename File
```powershell
cd "d:\Web Devlopment 2026\Practice\Day 2\One Page"
Rename-Item "indexx.html" -NewName "index.html"
```

### Step 2: Create GitHub Account
```
https://github.com/signup
```

### Step 3: Create Repository
```
Click "+" → "New repository"
Name: codenibbler
Public: YES
Create
```

### Step 4: Upload Files
```
Click "Add file" → "Upload files"
Drag all your files
Click "Commit changes"
```

### Step 5: Enable Pages
```
Settings → Pages
Source: main branch
Folder: / (root)
Save
Wait 2-3 minutes
```

### Your URL
```
https://YOUR-USERNAME.github.io/codenibbler
```

**DONE! 🎉**

## ✅ Critical: Rename indexx.html

**BEFORE uploading, rename your file:**

```powershell
Rename-Item "indexx.html" -NewName "index.html"
```

**Why?** Web servers look for `index.html` as the home page.
